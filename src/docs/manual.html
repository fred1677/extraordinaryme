SEC 1 Authentication & Role Elevation Flow

  • Bootstrap Admin Role: The first registered user automatically receives the admin role; all subsequent accounts receive standard user status[cite: 5].
  • Dynamic Identity Entry: The primary input toggles from Username or Email during login to Username or User ID during registration, where a distinct email field is dynamically revealed.
  • Client Persistence: Authentication JWTs and profile objects persist under auth_token and auth_user in browser localStorage[cite: 5].

Security Note: Logging out purges both keys from local storage and redirects immediately to the login screen[cite: 5].

SEC 2 Legal Governance (Decoupled Module)

  • Centralized Terms File: All legal terms, version markers, and revision dates reside in src/legals.js inside the LEGAL_TERMS constant[cite: 2].
  • In-App Modal Inspection: Users inspect legal agreements via showLegalModal(), keeping them within the signup workflow without redirects[cite: 2].
  • Zero-Downtime Maintenance: Legal text can be modified directly within src/legals.js without touching login form validation or the database schema[cite: 2].

SEC 3 Centralized UI Button Factory

  • Master Component Factory: Located at src/components/buttons.js, supplying standardized button elements, link anchors, and uniform padding across themes[cite: 7].
  • Pre-Configured Global Actions: Call StandardButtons.help(), StandardButtons.admin(), StandardButtons.backHome(), or StandardButtons.logout() for standard navigation controls[cite: 7].
  • Inline Topic Triggers: Call StandardButtons.sectionInfo(topicKey) to add an inline contextual ℹ️ icon to any card header[cite: 7].

SEC 4 Two-Tiered Help Architecture

  • Global Knowledge Portal: The primary ❓ Help button stays directly left of the Log Out button in navigation headers, routing to #help[cite: 5, 6].
  • Role-Filtered Content: The full help view renders operational maintenance guidance for admins while displaying only foundational companion basics to standard users[cite: 5].
  • Inline Module Tips: Contextual triggers invoke openHelpModal(topicKey), reading from src/utils/helpContent.js[cite: 6]. Help items marked adminOnly: true are hidden from standard accounts[cite: 6].

SEC 5 Administrative Console & Security Policies

  • Live Runtime Rule Modification: Adjust credential lengths and character requirements via the Admin Console; changes apply immediately to new registrations without a server reboot[cite: 6].
  • 30-Day Production Enforcement: Triggering production enforcement sets accounts out of compliance on a 30-day grace period countdown[cite: 6].
  • User Lifecycle Management: Administrators can deactivate accounts or permanently remove users directly from the console[cite: 6].
